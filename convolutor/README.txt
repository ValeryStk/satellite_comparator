================================================================================
ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ СКРИПТА СПЕКТРАЛЬНОЙ СВЕРТКИ
================================================================================

ОПИСАНИЕ
--------
Скрипт выполняет спектральную свертку (конволюцию) данных высокого разрешения 
под конкретные спектральные каналы выбранного спутника. Программа загружает 
исходный спектр, при необходимости обрезает его по длинам волн, пересчитывает 
значения с учетом функций спектральной чувствительности (SRF) спутника и 
сохраняет итоговые таблицы и графики.


1. ТРЕБОВАНИЯ И УСТАНОВКА ЗАВИСИМОСТЕЙ
--------------------------------------
Для работы скрипта необходим Python 3 и библиотеки numpy и matplotlib.
Установить их можно через терминал командой:

    pip install numpy matplotlib


2. ПОДГОТОВКА ВХОДНЫХ ДАННЫХ
----------------------------
1) Файл исходного спектра:
   - Текстовый файл (.txt или .dat), содержащий две колонки чисел:
     [длина волны в нм] и [значение отражательной способности].
   - Разделитель колонок: пробел или табуляция.
   - Строки комментариев должны начинаться с символов '#' или ';'.

2) Конфигурация спутника (SRF):
   - Поместите JSON-файл с характеристиками каналов в специальную папку 
     (по умолчанию используется папка "responses").
   - Имя файла должно соответствовать шаблону: 
     <имя_спутника>_responses.json или <имя_спутника>.json 
     (например: sentinel2A_responses.json).
   - Структура JSON: список объектов (каналов), где каждый объект содержит 
     обязательные ключи:
       * "physicalBand"        - название канала (строка)
       * "spectral_response"   - массив значений чувствительности (список чисел)
       * "wavelength_MIN_nm"   - минимальная длина волны канала (число)
       * "wavelength_MAX_nm"   - максимальная длина волны канала (число)
       * "wavelength_CENTRAL_nm" - центральная длина волны канала (число)


3. ПАРАМЕТРЫ ЗАПУСКА (АРГУМЕНТЫ КОМАНДНОЙ СТРОКИ)
------------------------------------------------
Обязательные параметры:
  -f, --file           Путь к текстовому файлу исходного спектра.
  -s, --satellite      Тип/имя спутника (например: sentinel2A, landsat8).

Опциональные параметры:
  -r, --responses-dir  Папка с JSON-файлами чувствительности.
                       (По умолчанию: responses)
  -o, --output-dir     Папка для сохранения результатов и графиков.
                       (По умолчанию: results)
  --min                Минимальная длина волны обрезки спектра в нм.
                       (По умолчанию: 430)
  --max                Максимальная длина волны обрезки спектра в нм.
                       (По умолчанию: 950)


4. ПРИМЕРЫ ЗАПУСКА
------------------
(В примерах предполагается, что файл скрипта называется convolutor.py)

Базовый запуск с настройками по умолчанию:
    python convolutor.py -f data/my_spectrum.txt -s sentinel2A

Запуск с указанием всех путей и пользовательского диапазона длин волн:
    python convolutor.py -f spectrum.txt -s landsat8 -r ./srf_configs -o ./out --min 400 --max 1100


5. РЕЗУЛЬТАТЫ РАБОТЫ
--------------------
После завершения работы в выходной директории (по умолчанию "results") 
будут созданы два файла:

1) output_<спутник>.txt
   Текстовый файл с результатами свертки (разделитель — табуляция). 
   Содержит две колонки: центральная длина волны (wavelength_nm) и 
   рассчитанное значение сигнала (convolved_value), отсортированные 
   по возрастанию длины волны.

2) plot_<спутник>.png
   График визуализации:
   - Черная линия: исходный спектр (интерполированный с шагом 1 нм).
   - Полупрозрачные области: кривые спектральной чувствительности (SRF) каналов.
   - Красные точки с подписями: итоговые значения свертки для каждого канала.
