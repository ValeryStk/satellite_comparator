# Расчёт индексов по данным Sentinel‑2 L2A

Продукты Sentinel‑2 L2A содержат отражение на нижней границе атмосферы (BOA), но значения хранятся как целочисленные пиксели с оффсетом и масштабом. Для расчёта индексов (NDVI и др.) сначала нужно восстановить физическое BOA‑отражение.

## Оффсет BOA_ADD_OFFSET = -1000

В метаданных L2A задаются параметры вида:

<BOA_ADD_OFFSET band_id="0">-1000</BOA_ADD_OFFSET>  
...  
<BOA_ADD_OFFSET band_id="12">-1000</BOA_ADD_OFFSET>

Это означает, что при записи данных к значению BOA (умноженному на масштаб) применили сдвиг `-1000`. Обратное преобразование выполняется с **противоположным** знаком:

\[
BOA = \frac{DN - (-1000)}{10000} = \frac{DN + 1000}{10000}
\]

где DN — целочисленное значение пикселя, 10000 — масштабный коэффициент.

boa = (band_array.astype(float) + 1000.0) / 10000.0
